Type-Link-Model (TLM) — retired

This project is archived and no longer maintained.

TLM was a solo, unfinished experiment in text-first fact-based modelling: describing a domain as elementary facts written as plain sentences, then generating schemas, diagrams, docs and SQL from them.

In 2026 the pragmatic landing spot for “models as code” is LinkML, which is maintained and ships the generation pipeline TLM only sketched. The reasoning — and the two honest things you give up by moving from a fact-based tool to LinkML — is written up here:

→ Fact-based modelling and LinkML

The durable idea isn’t “use LinkML.” It’s to model just the facts, and to find them by talking with domain experts — using examples, natural language, and simple drawings. That outlives any particular tool.
